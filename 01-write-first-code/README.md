# 01. Escritura del primer código de C#

Módulo inicial enfocado en la sintaxis básica, la salida por consola y la interacción con el usuario[cite: 1].

## 🎯 Objetivos de Aprendizaje
- Escribir las primeras líneas de código en C#[cite: 1].
- Imprimir mensajes en consola usando distintas técnicas (`Console.WriteLine`, `Console.Write`)[cite: 1].
- Capturar datos de entrada desde la terminal con `Console.ReadLine()`[cite: 1].
- Formatear y manipular cadenas de texto mediante interpolación y concatenación[cite: 1].

## 📂 Contenido
1. `01-console-output/`: Primeros mensajes e impresiones en consola.
2. `02-user-input/`: Lectura de entradas del usuario.
3. `03-string-manipulation/`: Interpolación y secuencias de escape.
4. `04-exercise-custom-greeting/`: Ejercicio práctico de saludo personalizado.
5. `05-challenge-interactive-program/`: Desafío final del módulo.
